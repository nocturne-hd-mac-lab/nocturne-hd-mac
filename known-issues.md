- A complete conversion with interruption/resume and Japanese/English input-free startup checks passed on one Mac. Active conversion took 15 minutes 9.5 seconds; the current uninterrupted time is unmeasured. The previous uninterrupted run took 14 minutes 43.6 seconds. See the [technical notes](technical-notes.md#requirements-and-measurements) for measured time, space, frame coverage and quality. Human gameplay with that root remains **Unverified（未確認）**.
- Scene conversion uses the supplied layouts and original values without an Editor or external scene tools. Images retain their original formats, animation curves are preserved and Cubemap remains BC6H. The newly generated root passed Japanese and English silent, input-free background starts with the tested app: title-processing markers were reached with no exceptions or material-loading errors. This checks startup, not gameplay, video appearance or sound. Human gameplay and in-game movie appearance/audio with the new output remain **Unverified（未確認）**.
- On that Mac, the owner played an earlier Japanese/English app in Japanese through the first battle with a complete nine-donor material root and reported normal progression; its player log contained no exceptions. One ⌘Q exit from that earlier app followed Unity's normal shutdown sequence with no crash report. These observations do not establish gameplay or normal termination in the supplied eight-language app.
- The supplied app supports all eight original languages. Japanese and English passed silent, input-free background starts through title processing in the tested current app; all eight passed on an earlier app. Human gameplay has only been checked in Japanese with an earlier app. Other-language gameplay and long-text layout remain **Unverified（未確認）**. See the handbook's language section for selection and overrides.
- Traditional Chinese name entry has been fixed and checked with focused code tests, not human play. Select names from the on-screen character table; direct typing and OS IME input are not connected. Static inspection found no equivalent stopping stub in the other seven languages. Traditional Chinese and Korean fonts retain a few missing characters from the original fonts. Name-entry behavior during play remains **Unverified（未確認）**.
- Normal startup reports an unconfigured, missing, or unreadable material folder and lets you choose Quit. Unattended batch runs and dedicated verification builds log the error to `Player.log` and exit without a dialog. Focused code tests passed. The dialog in the packaged app and setup on another Mac remain **Unverified（未確認）**. See [Configure materials and open the app](handbook.md#configure-materials-and-open-the-app) for setup and folder permissions.
- A newly signed app may need permission to access your materials folder again, including folders on an external drive. If loading seems stuck, check for a macOS permission prompt behind other windows. A failed game-file load detected by the app now reports an error and exits. The external-drive permission flow still needs testing.
- Fullscreen resolution changes were checked on the developer’s Mac. External displays, connecting or disconnecting a display while the app is running, and reopening the app on a second display still need testing.
- The Xbox input fix addresses repeated down input while the controller is idle. The update also selects button prompts for recognized Xbox, PlayStation, and Switch controllers. Focused code tests passed. Physical controllers, including Xbox over USB and Bluetooth, still need testing on a Mac.
- Mid-game and later progression, DLC screens, save migration, another Mac, and gameplay or ordinary termination in the supplied eight-language app are **Unverified（未確認）**.
- Scene conversion uses the included `scene-template-supply/` folder and needs no Unity Editor or external scene-tool installation. Keep that folder beside `convert.py`. Changed suppliers and unsupported original scene-file versions stop conversion. The required FFmpeg and ffprobe executables, LGPL licenses, corresponding source and rebuild recipe are included in `media-tools/`. Python 3.11 and the pinned converter requirements remain necessary.
- Conversion keeps 4GB free by default. After installation, allow 18GB free (13.388GB reservation plus the floor); use `--keep-free-gb 22` for the maker's higher floor. Starting near the reservation plus floor can cause `--resume` to be refused for space before conversion; free extra room and retry with the same output and options. A 4GB-floor run and another Mac remain **Unverified（未確認）**.
- Videos use Apple's hardware encoder at quality 80. Every clip is checked over all frames against SSIM >= 0.990 and PSNR >= 47dB, alongside stream/frame/timing checks. Quality 90 is retried once only within the existing reservation; failure prevents a completed root manifest. Output bytes may differ even between runs on the same Mac; hashes are local to each conversion.
- The ad-hoc signed media tools were blocked in a local ZIP quarantine test and both started after removing only their quarantine attributes. Follow the handbook after checking the package's source, checksums and signatures. Actual download-host/browser behavior, clean-Mac installation and other VideoToolbox generations remain **Unverified（未確認）**.
- Shader workers are limited automatically by CPU and memory. The conservative estimate selects serial processing on 8/16GiB Macs; those machines remain untested. `--shader-workers 1` also selects serial shader conversion.
- The minimum macOS/RAM/chip requirements, download-host quarantine flow, and clean-Mac setup are **Unverified（未確認）**.
- All-mode supports `--resume` after interruption and `--reuse` with a new output when updating. Keep `.conversion-cache/` intact. Changed procedures and damaged outputs are rebuilt; videos from another Mac and older outputs without compatible checkpoints are converted again. Single-route diagnostic commands require empty outputs. See the handbook for commands.
- Conversion success and matching structure do not establish complete visual or gameplay correctness. Keep original saves and report specific failures using the handbook's redaction procedure.
- Late-game and ending reports may contain spoilers. Label them before sharing.
